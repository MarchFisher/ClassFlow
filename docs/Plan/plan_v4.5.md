## 1. 现状与目标（读码结论，已对齐 v4.0 代码）

1. **动作按钮已成墙，且无层级**：顶栏 [保存 撤销 重做 周次·自动排课·排课错误·锁定·主题]、左栏 [新建 导入快照 导出快照 编辑 新增·删除·筛选]，14 个动作全部是平铺 `QPushButton`，无分组、无主次、无"当前状态"表达（[mainwindow.cpp:67-201](src/ui/mainwindow.cpp#L67-L201)）。
2. **accent 仍几乎不可感知**：静止态全应用只有主按钮「自动排课」一颗彩钮。列表/菜单选中与输入焦点走 QSS `%SELECT_BG%`；但**课表选中格描边走 `option.palette.highlight()`**（[timetabledelegate.cpp:196](src/ui/timetable/timetabledelegate.cpp#L196-L197)），而全工程从不 `setPalette`，所以它恒为 Qt 默认蓝——**切绿/橙/青时选中格边框不变**，这是"主题色看不出作用"最直接的一处。
3. **明暗只是灰面翻转**：亮 `#F5F5F5` / 暗 `#303030` 两套中性盘按位换灰，无表面分层、暗色不够深（[theme.cpp:40-50](src/ui/theme/theme.cpp#L40-L50)）。
4. **无空态引导**：无数据启动只在状态栏打一行"请先新建或导入"（[mainwindow.cpp:253-260](src/ui/mainwindow.cpp#L253-L260)）。
5. **弹窗各自为政**：v4.0 已有 10+ 弹窗（Import/SnapshotImport/Filter/Add·Delete 双标签/Lock/EditInfo/ManualAdjust/CourseDetail/CourseList/ScheduleError，见 [ui/dialog/](src/ui/dialog/)），QSS 里没有一套公共 `QDialog` 圆角/标题行样式，观感靠默认控件硬凑。

目标（不变，仍成立）：**G1** 统一 token 与控件态，网格成为带衬底的"画布"；**G2** 让 accent 拥有系统性语义角色（静止态也能数出 ≥3 处）；**G3** 保留课表卡片为视觉主角。非目标：不改主窗口信息架构、不动排课/MVD/数据层。

## 2. 新 UI 长什么样（本稿主体）

│ ▸ 课表            │   │ ┌────┐┌────┐┌────┐         │  白底  │

图例：`●` 主操作（accent 实底）；`▲ 徽标` danger 计数；`▸ 小节标题` 次要文字；画布与窗口底拉开表面层级。

### 2.1 语义色 token（theme 侧增强，为一切观感的地基）

把 [theme.qss](src/ui/theme/theme.qss) 从"平铺色"扩成"语义 token 表"，全部由 `ThemeManager::renderQss` 注入（沿用 v2.2 占位符机制，纯新增不破坏）：

| 新增 token | 语义 | 落到哪 | 亮建议 | 暗建议 |
|---|---|---|---|---|
| `%SURFACE%` | 面板/画布衬底（比窗底更"浮"） | 弹窗、侧栏、右栏画布容器 | `#FFFFFF` | `#2A2A2E` |
| `%GRID_BG%` | 网格底（与表头分层） | 课表画布 | `#FFFFFF` | `#2A2A2E` |
| `%TEXT_SECONDARY%` | 次要说明文字 | 侧栏小节标题、副行、hint、状态栏前缀 | `#757575` | `#BDBDBD` |
| `%ACCENT_TINT%` | accent 浅衬底 | 选中项/生效态背景、徽标底 | accent 混白 ≈90% | accent 降亮 ≈60% |
| `%ACCENT_PRESSED%` | accent 按下（比实底更深） | 主操作 pressed | 实底压暗 | 实底提亮 |
| `%DANGER%/%DANGER_TINT%` | 错误语义（独立于品牌 accent） | 失败徽标、错误按钮、状态栏失败首词 | `#C62828`/`#FDEBEA` | `#EF9A9A`/深衬 |
| `%SURFACE_BORDER%` | 画布/面板描边 | 圆角容器 1px | `#DDD` | `#3E3E44` |

同时给 `ThemeManager` 补**显式取色访问器**（供 delegate / 徽标 / 状态栏取用，绕开 QSS 管不到的自绘位）：`accentColor()`、`accentTint()`、`dangerColor()`、`secondaryText()`（明暗跟随当前 `m_dark`）。

明暗两套质感（不是换灰）：

- **亮**：窗底略灰 `#EFF0F2` → 画布/弹窗 `#FFF` 浮起，弱 `#DDD` 描边，阴影用"色分 + 圆角"表达（QSS 无 box-shadow）。
- **暗**：窗底加深到 `#1E1F22`（现 `#303030`），画布 `#2A2A2E` 用 1px 高光描边勾勒轮廓、卡片衬其上反而更醒目；正文对比适度降低，不用纯白刺眼。

### 2.2 accent 语义角色（对齐现骨架的落点，替代旧稿"四项导航"）

> 原则不变：accent 只用于"可交互的重点"与"当前态"，禁止铺满。旧稿设想把左栏做成 checkable 导航，但 v4.0 左栏全是弹窗动作、没有视图页，该落点作废，改落下面五处：

| 角色 | 落点 | 现态 → 目标 |
|---|---|---|
| 主操作 | 「自动排课」、空态 CTA | 已有 → 保留（`primary`） |
| 生效态 | **筛选按钮**：有生效筛选时点亮（accent-tint 底 + accent 描边 + 文案尾缀"·2 条件"），无则扁平 | 无 → 新增（可交互的"当前态"，静态也看得见 accent） |
| 选中 / 焦点 | 列表项、菜单项（改 tint 浅衬，不用整块实色）、输入框焦点环（accent 描边） | 部分 → 统一走 tint |
| 选中格描边 | delegate 选中环：从 `option.palette.highlight()` 改为显式取 `ThemeManager::accentColor()` | 现在取 palette（切 accent 不变）→ 显式取 | 
| 数据强调 | 周次强调 / 排课结果"成功 N 条"首词随 accent；错误量走 danger（下表） | 无 → 新增 |

这样静止态稳定出现 3~4 处 accent（主操作 / 选中项 / 选中格 / 筛选生效），切蓝↔绿↔橙全应用可见、可感知。**danger 独立一套**，不与 accent 抢色：

| danger 落点 | 现态 → 目标 |
|---|---|
| 排课失败 | 「排课错误」按钮在失败数 >0 时带 danger 计数徽标（红底白字小胶囊），0 失败不显示 |
| 状态栏失败 | "失败 N 个教学班"首词染 danger；"成功 N 条"首词随 accent |
| 错误弹窗 | ScheduleError 标题/图标用 danger 语义 |

### 2.3 布局与控件精修（不重排骨架，只做分组与观感）

- **侧栏分组**：把左栏 7 个动作分成两节，各加一个 `%TEXT_SECONDARY%` 小节标题：
  - **「文件」**：新建 / 导入快照 / 导出快照
  - **「课表」**：编辑 / 新增 / 删除 / 筛选（筛选落在组尾，兼作 2.2 的"生效态开关"）
  节间留 8~10px 呼吸；按钮统一 min-height 44、11pt、4~6px 圆角 + 1px 细描边 + hover 提亮 / pressed 压暗 + `:focus` 环。
- **顶栏**：保持"保存/撤销/重做 ｜ 周次 · 自动排课 · 锁定 · 主题"现次序，只补主次间距与主操作视觉重心（自动排课独占 accent 实底、字号略大）。撤销/重做沿用"可点时着色、不可用灰"。
- **右栏画布**：给 `m_view` 外圈留 10px 白 + 圆角容器（1px `%SURFACE_BORDER%` 描边 + `%SURFACE%` 衬底），表头比正文多一层底；Stretch 撑满现状不变。
- **状态栏**：成功/失败首词着色 + 操作后清空提示不闪屏（详见 2.2 danger 表）。

### 2.4 空态引导页（"第一眼"的提升点）

无数据（未新建/导入）时中央覆盖一个轻量空态页替代只刷状态栏：居中一行引导文案（如"还没有课表，先导入数据或新建工作区"）+ 两个 accent CTA「新建… / 导入快照…」。有数据即整体隐藏。这是成本最低、观感收益最明显的一处，建议列入 P0。

### 2.5 弹窗一致性

给公共弹窗统一 objectName（如 `dialog/base`）走同一套 `QDialog` 样式：圆角、内边距、标题行（与正文区用 1px 分隔线区分）、按钮行右对齐。覆盖范围以 v4.0 现有弹窗为准（含 Add/Delete 双标签页签、EditInfo + TimeRoomEditor 编辑面板）；长卡列表（CourseList）与详情卡配色与网格卡同源 token，不再各配各的。

### 2.6 图标边界

主窗/侧栏**维持文字按钮**（分组小标题 + accent 点/徽标已够表达层级）。编辑类弹窗内既有 feather 子集（lock/unlock/edit-2/trash-2，[theme.qrc](src/ui/theme/theme.qrc)）保留，仅需校对它们在暗色 + 禁用态下的可读性（沿用 `baseForeground()` 取正文同色方案）。

## 4. 风险与边界

- Qt QSS 不支持 box-shadow：纵深用"色分 + 圆角 + 细描边"表达，不引自绘阴影。
- delegate 自绘不受 QSS 管：凡卡片/选中环/锁标等自绘色一律从 token 访问器显式取（与现有 `moreBackground()` 同模式），**不要再依赖 palette 角色**。
- 暗色窗底加深 `#303030→#1E1F22` 会改变卡片盘（`kCardBgDark`）的衬底对比，改色时走查一遍 10 色卡可读性。
- 纯视觉改动与逻辑解耦，随时可分步提交、人工走查后再进下一步；每个改动文件 <500 行。

## 5. 建议范围（待确认）

- **推荐 P0**：2.1 token + 2.2 accent 语义（选中格显式 accent / 筛选生效态 / danger 徽标 / 状态首词）+ 2.3 侧栏分组与按钮态 + 2.4 空态页 + 2.5 弹窗统一 → W1~W3。
- **P1 延展**：暗色更深窗底细调、周次等数据强调、图标扩到主窗（默认不做）。

## 6. 验收（P0）

1. 静止态能数出 ≥3 处 accent（主操作 / 选中项 / 选中格），切换 accent 全应用可见（选中格描边必须跟随）。
2. 暗色有真正纵深、亮色有表面分层；文字对比在明/暗 × 5 accent 下均达标。
3. 空数据有引导页；弹窗观感统一；网格有画布感；与课表卡片风格自洽。
4. `ctest` 9/9 无回归；改动文件 <500 行。
