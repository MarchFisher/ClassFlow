# ClassFlow 开发计划 v2.1

> 版本：v2.1 · 当前版本：v2.0 · 日期：2026-08-30 · 目标：筛选弹窗搜索栏交互重构

## 目标

修复 v2.0 筛选弹窗搜索栏的交互缺陷，确立并落地「**勾选栏为准、搜索栏仅前缀过滤、两者不同步**」这一实际需求。

### 需求演进背景（决策历程）

| 迭代 | 交互 | 问题 |
|------|------|------|
| v2.0 初版 | 搜索即选中：输入自动勾选命中项 + 勾选汇总回写搜索框 | ① 先勾选再搜索匹配不了（拿整串匹配）② 搜索自动勾选误伤 |
| v2.1 中间版 | 搜索只过滤 + 勾选汇总回写搜索框（两者同步） | 双向联动复杂、信号回环、同步语义绕，反复出 bug |
| **v2.1 定稿** | **勾选栏为准；搜索框仅前缀过滤；不同步** | 逻辑最简、职责清晰 |

## 需求（搜索栏实际需求）

### 核心原则

- **勾选栏（列表）是唯一真源**：勾选状态由用户手动维护，搜索不影响勾选，勾选不回写搜索框。
- **搜索框是纯过滤词**：输入即按子串过滤列表显示，仅用于快速定位；与勾选状态完全独立。

### 交互规格

| 规则 | 触发 | 行为 |
|------|------|------|
| R1 子串过滤 | 搜索框 `textChanged` | 取搜索框全文做**子串匹配**（大小写不敏感）过滤列表显示；空词 = 显示全部 |
| R2 勾选为准 | 列表项勾选 / 取消勾选 | 勾选状态只由用户手动维护；搜索不影响勾选，勾选不回写搜索框 |
| R3 清空 | 点「清空」按钮 | 取消三组全部勾选 + 清空三组搜索框（列表恢复全部显示）→ 回到「不限」 |

### 边界说明

- **无同步**：搜索框不显示勾选汇总，勾选/取消不回写搜索框 → 无信号回环，仅一个 `textChanged` 连接。
- **子串匹配**：`张三` 命中 `张三丰` 也命中 `李张三`；空词不过滤。
- 勾选时列表若被过滤，只能勾选到可见项；清空搜索框可恢复全部再勾。

## 决策记录

| 决策 | 结论 |
|------|------|
| 搜索命中是否自动勾选 | **否**（R2） |
| 搜索栏是否与勾选同步 / 显示汇总 | **否**。勾选栏为准，搜索栏独立（消灭信号回环） |
| 匹配方式 | **子串匹配**（大小写不敏感），非前缀 |
| 回车 / 失焦行为 | 无特殊处理（保持过滤视图）；清空搜索框或点「清空」恢复全部 |
| 清空按钮 | 顶部一个，取消勾选 + 清空搜索框，三组一起复位 |

## 验收

1. 输入 `张` → 列表只显示含「张」的条目（如 `张三`、`张三丰`、`李张三`）。
2. 过滤命中项**未自动勾选**；勾选状态与搜索无关。
3. 勾选若干项后，搜索框内容不变（不回写汇总）。
4. 清空搜索框 → 列表恢复全部显示，勾选保留。
5. 点「清空」→ 三组全部取消勾选、搜索框清空（回到「不限」）。
6. 无信号回环：勾选、输入互不干扰，可任意次序操作。
