## 1. 项目背景与目标

高校每学期需要为大量教学班安排「上课时间 + 教室」。人工排课依赖经验、耗时数天，且难以避免**教室冲突、教师撞车、容量不足**等问题，调整一次牵一发动全身。

**ClassFlow 的目标**：用一套桌面工具，把「排课」从人工作坊变成「导入数据 → 自动排课 → 出全校课表 → 编辑 / 人工微调 / 锁定 → 撤销与持久化」的流水线，在几分钟内完成人工数天的工作，并保证硬约束全程不违反、局部改动不动其余结果、误操作可撤销、没保存也能找回现场。

**演进路径**

- v1.0（MVP）：贪心自动排课，打通「数据导入 → 排课 → 课表展示」全链路；
- v2.x：筛选、主题系统、课程详情、失败诊断、快照与工作区持久化；
- v3.0：排课升级**贪心 + 模拟退火两阶段**，引入软约束加权罚分体系；
- v3.1：store 按职责拆分，课程/教学班/教师/教室 ID 索引 O(1) 查询；
- v3.2：排课**异步化**（后台线程跑副本、进度/取消、取消保旧表）；
- v3.3：课表网格 **MVD 自绘**（逐卡着色 + 像素命中 + 「更多」列表）、主窗口拆分出排课/课表两个控制器、教师姓名显示；
- v3.4：**锁定与局部重排**（可动集合 movable / 冻结统一引擎、一键锁整门课、锁定随快照持久化）；
- v3.5：**课程 / 教学班实体分离**（以 courseId 为主键、课程可空、删班不删课、快照 `[Courses]` 段、双标签新增与删除、新增班最小排 + 放不下升格局部重排）；
- v3.6：**教务手动调整**（点卡片详情内调整本课，本节 / 整班两种模式，只查硬约束、整批原子改排课条目）；
- v4.0：以上能力全部落地，文档对外版本统一为 v4.0；
- v4.1：快照加载一致性**告警**（`loadWarnings`）、硬约束 H4/H5 判定**单源 roomrules**、排课条目**代理主键 entryId**（`classId#序号`，与时间解耦）、**会话级撤销 / 重做**、排课条目 **O(1) 索引**；
- v4.2：课程与教学班**基本信息编辑**（改名 / 学院 / 换师 / 人数 / 容量，换师撞车登记延迟应用）；教务手动调整 **并入「编辑」双页签**（基本信息 + 时间·教室一次保存）；
- v4.5：**UI 视觉优化**——语义主题 token、亮/暗表面分层、accent 作用可感知（选中格描边、筛选点亮、danger 独立）、**空态引导页**、顶栏按钮图标化与统一资源目录；
- v4.6：**双层保存**——L1 防抖自动恢复 + L2 项目文件 + 「导出快照」独立副本 + 标题脏标记 ●；
- **v5.0（当前）**：应用图标（运行期窗口 + exe 程序图标）；文档与版本统一，上述全部能力收拢为本版产品现状。

## 2. 产品定位

- **使用对象**：教务管理员（当前单机版，无账号体系）
- **形态**：Windows 桌面应用（Qt Widgets，C++17 编写）
- **数据入口**：CSV 文件——教学班、教室、作息表三份必选，另可选教师清单；或直接**导入既有工作区快照**
- **数据出口**：全校课表网格 + 工作区快照（手动存档 / 独立副本 / 自动恢复）
- **系统要求**：随时能保存、能反悔（Ctrl+S / 撤销·重做 / 崩溃自动恢复）

## 3. 功能需求

### 3.1 数据导入

- 一次导入**教学班、教室、作息表**三份 CSV（教师 CSV 可选），自动解析入库
- 教学班文件**内嵌课程字段**（含 courseId / 课程名 / 学分 / 每周课次 / 单次学时 / 学院 / 周范围 / 所需教室类型），按 **courseId 主键**识别课程并去重建档（同一门课多班共享，不重复建档）；课程模板与教学班**相互独立**，允许空课程
- 教师清单可选：缺失时由教学班行的 teacherId 去重推导
- 教室类型自动识别：普通教室 / 机房 / 操场，分别匹配不同课程需求
- 作息表即「第几节 · 起止时间」，决定每天可用的时间槽
- 周范围（startWeek / endWeek）与所需教室类型随课程字段录入
- 另支持从九段工作区快照直接**导入既有现场**（含课程实体 / 锁定 / 失败明细），导入成功即成为新的工作区与项目文件基线

### 3.2 自动排课（两阶段）

- **① 贪心构造可行初始解**：先排「每周课次多、单次学时多」的难排教学班；同课程教学班共用同一套时间模式（间隔 `(5−N)/(N−1)` 天），教室不足时按 classId 兜底拆分、时间间隔逐步放宽；教室 best-fit（容量 ≥ 人数且最小），并匹配课程所需类型（H5，经 `roomrules` 单源判定）。
- **② 模拟退火优化**：以贪心解为起点，通过 M1~M5 五种邻域操作（单课平移 / 整班平移 / 课程归并 / 换教室 / 双班对调）反复微调，按 Metropolis 概率接受，best-so-far 保证**返回成本 ≤ 贪心解**；全程硬约束零违反。
- **课次守恒**：全程保证每班恰排够 `sessionsPerWeek` 次课（回归测试覆盖，防止邻域操作吞课次）。
- **异步不阻塞**：后台线程排「数据副本」，主线程旧课表不动、可继续浏览；可取消，取消保留旧课表；排课期间相关入口禁用防半截写盘。
- **可动集合 / 冻结**：一次排课由可动教学班集合 M 描述——冻结班（已排且 ∉ M）的原排课条目**原样种入冲突表占位**，贪心与退火都只动 M。同一引擎四种取法：全量排（M=全部班）、**锁定重排**（M=全部未锁定班）、**新增班最小排**（M=刚新增的班）、**单班局部重排**（M={某班}，编辑扩容换大教室等场景）。**被锁定的班在重排中一像素不动。**

### 3.3 约束体系

**硬约束 H1~H5（零违反，冲突即拒绝）**

| 编号 | 约束 | 说明 |
|------|------|------|
| H1 | 同班时间互斥 | 同一教学班各次课时间不冲突 |
| H2 | 同教室同时间唯一 | 同一教室同一时间只能安排一个班 |
| H3 | 同教师同时间唯一 | 同一教师同一时间只能上一门课 |
| H4 | 容量满足 | 教室容量必须 ≥ 教学班预期人数 |
| H5 | 类型匹配 | 教室类型匹配课程所需类型（Any = 不限；实验→机房、体育→操场） |

**软约束 S1~S7（加权罚分，越小越好）**

| 编号 | 软约束 | 罚分含义 |
|------|--------|----------|
| S1 | 课程不拆分 | 同一课程尽量保持同一时间模式 |
| S2 | 时间离散度 | 两次课之间尽量隔理想天数 |
| S3 | 同班同教室 | 教学班各次课尽量用同一教室 |
| S4 | 教室利用率 | 容量 − 人数的浪费尽量小 |
| S5 | 时间负载均匀 | 各时间槽并发上课班数尽量均衡 |
| S6 | 教室负载均匀 | 各教室占用节数尽量均衡 |
| S7 | 避免周末上课 | 周六/日每课次高额罚分，尽量把课排在工作日 |

> 权重实现口径：内部全部 ×2 整数化保证十万级 move 位精确、无浮点漂移；名义值见 [docs/algorithms/simulated-annealing.md](../algorithms/simulated-annealing.md) §7。

### 3.4 锁定与局部重排

- **锁定粒度**：整教学班；支持**一键锁整门课**（循环锁定其下全部教学班）；不做单节冻结
- 排课入口（顶栏「自动排课」）按**当前锁定集**冻结已锁有课班、只重排其余未锁定班；已锁班已排条目逐字段原样保留
- 语义提示：已失败（未排上课）的班即使被锁，重排仍会尝试安排，否则会变“永不排”
- 锁定状态随工作区快照 `[Locks]` 段持久化；课程详情内可对单班「锁定 / 解锁本班」

### 3.5 课程 / 教学班编辑（增删 + 基本信息，一次 = 一步撤销）

- **新增（侧边栏「新增」→ 双标签）**
  - 「新增课程」：建**空课程**（课程号唯一），不排课、课表不动；
  - 「新增教学班」：选某课程号（含空课）→ 预览自动带出该课程信息 → 提交后对**新班做最小排**（存量 0 扰动）；放不下则弹窗询问是否**升格局部重排**（未锁定班才动）。
- **删除（侧边栏「删除」→ 双标签）**
  - 「删除课程」：整门删除（含其全部教学班、排课、锁定），**含空课程**；
  - 「删除教学班」：按课程分组勾选单班 / 级联删除，**删班永不自动删课**——删到某课最后一个班，课程保留为空课程，另在「删除课程」页整门移除。
- **基本信息编辑**：课程名 / 开课学院（课程层），任课教师 / 计划人数 / 最大容量（教学班层）可改。两处入口共享同一表单：
  - 侧栏「编辑」（浏览式，课程 / 教学班双页签）：覆盖**空课 / 未排班的课 / 整门改名**等"不在课表上"的维护场景；
  - 课表点卡片 → 课程详情 →「编辑」：`ClassEditDialog` **双页签一次保存**（页签1 基本信息 + 页签2 时间·教室），先落排课后落基本信息。
- **改动的安全语义**：
  - 改名 / 学院 / 人数：即时生效，重排即可按新值收紧或放宽；
  - **换师撞车 → 不自动排**：新教师在该班现有时段有课则拒绝应用，只登记到冲突列表、弹提示；教务把该班腾到新师空闲时段后重新换师即应用（数据层 `reassignClassTeacher` 连带改写全部已排条目的冗余教师，换师后按教师查课表不失联）；
  - **扩容超当前教室容量**：确认后对该班做**单班局部重排**换大教室（未锁定时可跨天调整）；确认放弃则不落库。
- 识别课程一律用**课程号（courseId 主键）**，允许同名不同号；一次增删 / 编辑 = **一步撤销**。

### 3.6 教务手动调整（并入「编辑」双页签）

- 入口：课表点卡片 → 课程详情 →「编辑」→「时间·教室」页签
- 直接改排课条目（时间 / 教室），**不经排课线程 / 退火**；只校验硬约束 H1~H5，软约束不管
- 两种排他模式：
  - **本节**：只改当前选中的那次课；
  - **整班（N 次课）**：列出该班全部现存课次，各行独立选星期 / 起始节 / 教室，一次保存做**原子整批校验 + 落库**（批内自撞也会被拦截）。
- 该页签与基本信息同处一个对话框：一次「保存」先落排课改动、再落基本信息改动，一步入撤销环
- 每次课是独立对象：同班各次课可各落不同时间 / 不同教室
- 不改周范围；课长 = 原条目跨度；改起始节时结束节不超作息最大节
- 失败即停在对话框，按行号提示中文原因（该教室时段被占 / 与本班冲突 / 该教师此时段有课 / 容量不足 / 类型不符 / 范围越界 / 条目不存在），**整体不写库**
- 未排课的班该页签禁用并提示；调完**不自动锁定**；如需本次结果在后续「自动排课 / 局部重排」保留，请随后在详情锁定该班

### 3.7 会话级撤销 / 重做

- 顶栏 撤销 / 重做 图标钮 + Ctrl+Z / Ctrl+Shift+Z
- **可撤销动作**：新建 / 导入快照 / 新增课程·教学班 / 删除 / 锁定 / 基本信息编辑 / 手动调整 / 自动排课；课程详情窗口内一段会话的 锁定 / 编辑 / 调整 / 删除 合并为一步
- 动作前状态入**值环**（上限 20 步），撤销后课表、详情、空态页同步刷新；排课 busy 期间禁用
- 不做可撤销的：保存 / 导出 / 周切换 / 筛选 / 主题

### 3.8 双层保存

- **L1 自动恢复（不必按保存）**：任意改动后 ~1.5s 防抖自动写 `.classflow/workspace.dat`（内容未变不空写），关窗 / 新建前再补一次 → 启动总从它恢复，没保存过也能回到上次现场（VSCode 式）
- **L2 项目文件（显式存档）**：Ctrl+S / 顶部「保存」写教务选定的**项目文件**；首次保存 = 选路径（导出语义），之后直接覆盖，路径跨会话记住；窗口标题带脏标记 **●**（= 当前内容尚未存档到项目文件）
- **「导出快照」= 独立副本**：侧栏导出另存一份当前现场，**不设为当前项目文件**、不影响 Ctrl+S 落点，可分发给他人 / 备份 / 二次排课
- 快照为九段文本，老文件 / 老版本兼容（见 §3.9）

### 3.9 快照与工作区

- **单文件快照九段**：`[Term] / [Courses] / [TeachingClasses] / [Teachers] / [Classrooms] / [Sections] / [ScheduleEntries] / [ScheduleErrors] / [Locks]`；导入 / 导出 / 自动恢复 / 项目文件同构
- **`[Courses]` 是课程事实唯一权威**：班行内嵌课程列与 `[Courses]` 逐字段核对，不一致**以课程段覆盖并记入加载告警**（老快照缺 `[Courses]` / `[Locks]` 照常打开：分别推导 / 留空）；有覆盖发生时状态栏提示"部分课程数据已按课程段校准"
- 锁定、失败明细随快照持久化，缺段不阻断

### 3.10 全校课表展示

- **横看周几、竖看第几节**（符合阅读习惯），周一至周日 × 每日节次，支持按周切换
- 同一时间格多班上课（不同教室）时，**多行卡片堆叠**显示，课程名 + 教师·教室一目了然；卡片可点击直达详情
- 一格课程较多时展示前 2 张完整卡 + 1 张「更多 +N」卡位，点「更多」弹长卡列表（含未折叠全部课程）
- 多学时课程一次课跨连续多节（节次区间完整渲染，跨节不破）；无课时间格留空
- 选中格以主题 **accent 描边**；卡片按主题语义取色，随明暗 / accent 变换
- 卡片详情动作：查看课程信息 / 锁定解锁本班 / 编辑（基本信息 + 时间·教室）/ 删除本节 / 删除整课

### 3.11 筛选、详情与诊断

- **筛选**：按教师 / 教室 / 课程多选过滤课表，快速定位；筛选生效时侧栏「筛选」按钮**点亮并显示条件数**，便于识别当前视图已被过滤
- **课程详情**：点击课表卡片查看课程信息（每周课次 / 单次学时 / 教师 / 教室 / 周范围等）并在详情内完成 锁定 / 编辑 / 删除（本节 / 连整门课）
- **失败诊断**：排不下时列出失败教学班与归因（无对应类型教室 / 容量不足 / 时间冲突 / 教师撞车…），顶栏「排课错误」带 danger 计数徽标；班补排 / 换师成功后对应失败记录自动清除

### 3.12 主题系统

- **明 / 暗（可跟随系统）× 蓝 / 绿 / 紫 / 橙 / 青** accent；偏好跨会话记忆
- 亮暗两套改为**表面分层**：亮色窗底略灰、画布 / 弹窗浮起；暗色窗底加深、画布带高光描边
- 语义配色：主操作实底（accent）、筛选点亮 / 列表选中浅衬、选中格描边、危险（排课错误 / 状态栏失败首词）独立 danger 色、禁用态独立落灰、次要文字次浅
- 课表卡片随主题着色，切 accent 全应用可见；图标随主题换色、禁用态自动落灰

### 3.13 空态引导

无教学班数据（未新建 / 未导入）时，右侧显示**空态引导页**：一句引导文案 + 两个 CTA（「新建…」/「导入快照…」），取代单行状态栏提示；空课程（课程存在但无班）同样视作空。

### 3.14 应用图标与运行期防误操作

- **应用图标**：`icons/classflow.png`（运行期窗口 / 标题栏 / 任务栏 / 弹窗）+ `icons/classflow.ico`（windres 嵌入 exe，资源管理器 / 快捷方式）
- **运行期防误操作**：排课进行中，自动排课 / 锁定 / 撤销 / 重做 / 新建 / 导入快照 / 导出快照 / 新增 / 删除 / 编辑 / 筛选等入口一律禁用（顶部「保存」除外，排课期间写的是不动的静态数据，安全），防半截结果写盘

## 4. 典型使用流程

```
① 准备 CSV（教学班 / 教室 / 作息表，可加教师清单），或直接用旧工作区快照
        ↓
② 点击「新建」，选择文件（导入即自动排课；后台线程跑，随时可取消）
        ↓
③ 查看全校课表；用筛选 / 详情 / 排课错误核对，改选周次
        ↓
④ 需要维护课程表：新增课程/教学班（最小排）、删除课程/班（删班不删课）
        ↓
⑤ 改基本信息：课程名 / 学院 / 教师 / 人数 / 容量（换师撞车只登记不硬排）
        ↓
⑥ 局部微调：点卡片 → 详情 →「编辑」→「时间·教室」页挪某次课/整班时间或教室
        ↓
⑦ 定稿前「锁定」要保留的班；再次「自动排课」只动未锁定班
        ↓
⑧ 反悔就 Ctrl+Z（或顶栏撤销）；Ctrl+S 存到项目文件 / 导出快照另存独立副本
   —— 全程任意改动自动记忆，崩溃 / 退出后重开即回到现场
```

## 5. 验证成果

**示例数据规模**：11 个教学班 · 6 门课程 · 23 间教室（普通/机房/操场）· 每天 8 节；另有 18 班大批量压力用例

| 项目 | 结果 |
|------|------|
| 自动排课 | 示例班全部排上，每班恰排够每周课次 |
| 冲突数（教室/班级/教师） | 0 |
| 容量 / 类型违规 | 0 |
| SA 相对贪心 | 总软成本 ≤ 贪心；时间/教室负载方差大幅压匀 |
| 锁定重排 | 锁定班条目逐字段不动，其余重排零冲突 |
| 新增班最小排 | 存量 0 扰动插入；拥挤场景升格局部重排询问 |
| 基本信息编辑 | 改名 / 换师即时落库；换师撞车不应用只登记；扩容触发单班局部重排 |
| 教务手动调整 | 整批原子落库；任一节冲突即整批拒绝且不写库；拒绝原因细分 R/C/T |
| 撤销 / 重做 | 新建 / 导入 / 增删 / 锁定 / 编辑 / 调整 / 排课均可回退，换源后刷新一致 |
| 双层保存 | 防抖写盘指纹比对不空写；Ctrl+S 落项目文件带 ● 脏标记；导出不影响落点；关闭重开恢复现场 |
| 快照 | 九段往返一致；`[Courses]` 权威覆盖 + 加载告警；缺段容错；老快照兼容 |
| 自动化测试 | 9 个 QtTest 套件全部通过 |

> 测试覆盖：CSV 解析与导出往返、快照往返（含 `[Courses]` / `[Locks]` 段与缺段容错、课程一致性校验与告警）、冲突检测、贪心排课正确性、筛选判定、模拟退火（硬约束零违反、成本不劣于贪心、负载均匀性、同种子可复现、课次数守恒、多学时跨节、周末罚分）、锁定冻结与最小排零扰动、手动调整（容量/类型/范围/缺失拒绝、批内自撞、整批回滚不写库）、撤销/重做、entryId 兼容、课表点击命中回归。

## 6. 技术架构概要

```
表现层（Qt Widgets：主窗口(顶栏+侧栏+右栏画布/空态页) / 弹窗 导入·筛选·新增·删除·锁定·
       详情·「编辑」双页签(基本信息 + 时间·教室) / 课表 MVD / 主题系统 + 主题色图标）
   ↓
编排 / 校验（ScheduleController：后台线程 + 最小排升格局部重排收口；TimetableController；
       editui 落库决策助手；core/schedule/manualmove 手动调整纯校验）
   ↓
排课核心（贪心 + 模拟退火，纯逻辑、可单测；movable/冻结统一引擎；roomrules H4/H5 单源；
       ConflictTable 拒绝保证硬约束零违反）
   ↓
数据层（CSV 导入/导出、九段工作区快照 + snapshotText 指纹、自动恢复/项目文件双层保存、
       内存数据仓库 + 五张 ID 索引 O(1) 查询 + UndoBuffer 值环）
   ↓
数据模型（课程 / 教学班 / 教师 / 教室 / 作息 / 排课条目，courseId 主键实体分离）
```

- 四层严格分离，核心逻辑**不含界面代码**，可用自动化测试独立验证
- 纯 C++17 + Qt6 Widgets（+ Qt Svg 图标渲染），Windows windres 嵌入图标

## 7. 局限与后续规划

**当前局限**
- 单机版，无账号与角色区分，仅服务管理员排课
- 软约束权重为固定建议值，未在 GUI 暴露调节入口
- 手动调整仅改时间 / 教室，不支持删单节、补排缺失节、按周跳过
- 锁定粒度为整班（无单节冻结）；未做"手动结果自动排永久优先"的独立特性
- 撤销环上限 20 步，仅会话级（不跨进程持久化）
- 全空工作区（教学班全删光）新建 / 重开暂不支持

**已规划的下一步**
- 教师个人课表、学生个人课表
- 选课与学生名单（选课后冲突检测预留）
- GUI 暴露软约束权重调节（均匀性 / 拆分 / 周末罚分的权衡滑块）
- 手动调整增强：整班刚性平移 / 一键同教室、批内自由挑课次、永久手动优先
- 撤销 / 重做跨会话持久化或更大容量；全空工作区支持
