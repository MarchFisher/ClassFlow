# ClassFlow 高校自动排课系统 — 产品需求文档（v4.0）

> 版本：v4.0 · 日期：2026-09-03 · 状态：历史版本（已被 [ClassFlow_v5.0.md](./ClassFlow_v5.0.md) 取代）
> 版本口径：v1.0~v3.x 期间按实现里程碑演进（详见 §1 演进路径）；**v4.0 起对外版本统一**，
> 将 v3.1~v3.6 已实现的全部能力（两阶段排课 / 异步化 / 课表 MVD / 锁定局部重排 /
> 课程与教学班编辑 / 教务手动调整）作为产品现状收拢在本版。

---

## 1. 项目背景与目标

高校每学期需要为大量教学班安排「上课时间 + 教室」。人工排课依赖经验、耗时数天，且难以避免**教室冲突、教师撞车、容量不足**等问题，调整一次牵一发动全身。

**ClassFlow 的目标**：用一套桌面工具，把「排课」从人工作坊变成「导入数据 → 自动排课 → 出全校课表 → 人工微调 / 锁定 → 持久化」的流水线，在几分钟内完成人工数天的工作，并保证硬约束全程不违反、局部改动不动其余结果。

**演进路径**

- v1.0（MVP）：贪心自动排课，打通「数据导入 → 排课 → 课表展示」全链路；
- v2.x：筛选、主题系统、课程详情、失败诊断、快照与工作区持久化；
- v3.0：排课升级**贪心 + 模拟退火两阶段**，引入软约束加权罚分体系；
- v3.1：store 按职责拆分，课程/教学班/教师/教室 ID 索引 O(1) 查询；
- v3.2：排课**异步化**（后台线程跑副本、进度/取消、取消保旧表）；
- v3.3：课表网格 **MVD 自绘**（逐卡着色 + 像素命中 + 「更多」列表）、主窗口拆分出排课/课表两个控制器、教师姓名显示；
- v3.4：**锁定与局部重排**（可动集合 movable / 冻结统一引擎、一键锁整门课、锁定随快照持久化）；
- v3.5：**课程 / 教学班实体分离**（以 courseId 为主键、删班不删课、空课程可存盘、双标签新增与删除、新增班最小排 + 放不下升格局部重排）；
- v3.6：**教务手动调整**（点卡片详情内「调整本课」，本节 / 整班两种模式，只查硬约束、整批原子改排课条目）；
- **v4.0（当前）**：以上能力全部落地为产品现状，文档版本统一为 v4.0。

## 2. 产品定位

- **使用对象**：教务管理员（当前单机版，无账号体系）
- **形态**：Windows 桌面应用（Qt Widgets，C++17 编写）
- **数据入口**：CSV 文件——教学班、教室、作息表三份必选，另可选教师清单
- **数据出口**：全校课表网格 + 工作区快照 + 结果导出 + 记忆文件持久化

## 3. 功能需求

### 3.1 数据导入

- 一次导入**教学班、教室、作息表**三份 CSV（教师 CSV 可选），自动解析入库
- 教学班文件**内嵌课程字段**（含 courseId / 课程名 / 学分 / 每周课次 / 单次学时 / 学院 / 周范围 / 所需教室类型），按 **courseId 主键**识别课程并去重建档（同一门课多班共享，不重复建档）；课程模板与教学班**相互独立**，允许空课程
- 教师清单可选：缺失时由教学班行的 teacherId 去重推导
- 教室类型自动识别：普通教室 / 机房 / 操场，分别匹配不同课程需求
- 作息表即「第几节 · 起止时间」，决定每天可用的时间槽
- 周范围（startWeek / endWeek）与所需教室类型随课程字段录入

### 3.2 自动排课（两阶段）

- **① 贪心构造可行初始解**：先排「每周课次多、单次学时多」的难排教学班；同课程教学班共用同一套时间模式（间隔 `(5−N)/(N−1)` 天），教室不足时按 classId 兜底拆分、时间间隔逐步放宽；教室 best-fit（容量 ≥ 人数且最小），并匹配课程所需类型（H5）。
- **② 模拟退火优化**：以贪心解为起点，通过 M1~M5 五种邻域操作（单课平移 / 整班平移 / 课程归并 / 换教室 / 双班对调）反复微调，按 Metropolis 概率接受，best-so-far 保证**返回成本 ≤ 贪心解**。
- **课次守恒**：全程保证每班恰排够 `sessionsPerWeek` 次课（回归测试覆盖，防止邻域操作吞课次）。
- **可动集合 / 冻结（v3.4）**：一次排课由可动教学班集合 M 描述——冻结班（已排且 ∉ M）的原排课条目**原样种入冲突表占位**，贪心与退火都只动 M。同一引擎三种取法即得到：全量排（M=全部班）、**锁定重排**（M=全部未锁定班）、**新增班最小排**（M=刚新增的班）。**被锁定的班在重排中一像素不动。**

### 3.3 约束体系

**硬约束 H1~H5（零违反，冲突即拒绝）**

| 编号 | 约束 | 说明 |
|------|------|------|
| H1 | 同班时间互斥 | 同一教学班各次课时间不冲突 |
| H2 | 同教室同时间唯一 | 同一教室同一时间只能安排一个班 |
| H3 | 同教师同时间唯一 | 同一教师同一时间只能上一门课 |
| H4 | 容量满足 | 教室容量必须 ≥ 教学班预期人数 |
| H5 | 类型匹配 | 教室类型匹配课程所需类型（Any = 不限；实验→机房、体育→操场） |

**软约束 S1~S7（加权罚分，越小越好）**

| 编号 | 软约束 | 罚分含义 |
|------|--------|----------|
| S1 | 课程不拆分 | 同一课程尽量保持同一时间模式 |
| S2 | 时间离散度 | 两次课之间尽量隔理想天数 |
| S3 | 同班同教室 | 教学班各次课尽量用同一教室 |
| S4 | 教室利用率 | 容量 − 人数的浪费尽量小 |
| S5 | 时间负载均匀 | 各时间槽并发上课班数尽量均衡 |
| S6 | 教室负载均匀 | 各教室占用节数尽量均衡 |
| S7 | 避免周末上课 | 周六/日每课次高额罚分，尽量把课排在工作日 |

> 权重实现口径：内部全部 ×2 整数化保证十万级 move 位精确、无浮点漂移；名义值见 [docs/algorithms/simulated-annealing.md](../algorithms/simulated-annealing.md) §7。

### 3.4 锁定与局部重排（v3.4）

- **锁定粒度**：整教学班；支持**一键锁整门课**（循环锁定其下全部教学班）；不做单节冻结
- 排课入口（顶栏「自动排课」）按**当前锁定集**冻结已锁有课班、只重排其余未锁定班；已锁班已排条目逐字段原样保留
- 语义提示：已失败（未排上课）的班即使被锁，重排仍会尝试安排，否则会变“永不排”
- 锁定状态随工作区快照 `[Locks]` 段持久化；详情弹窗内可对单班「锁定 / 解锁本班」

### 3.5 课程 / 教学班编辑（新增与删除，v3.5）

- **新增（侧边栏「新增」→ 双标签）**
  - 「新增课程」：建**空课程**（课程号唯一），不排课、课表不动；
  - 「新增教学班」：选某课程号（含空课）→ 预览自动带出该课程信息 → 提交后对**新班做最小排**（存量 0 扰动）；放不下则弹窗询问是否**升格局部重排**（未锁定班才动）。
- **删除（侧边栏「删除」→ 双标签）**
  - 「删除课程」：整门删除（含其全部教学班、排课、锁定），**含空课程**；
  - 「删除教学班」：按课程分组勾选单班 / 级联删除，**删班永不自动删课**——删到某课最后一个班，课程保留为空课程，另在「删除课程」页整门移除。
- 识别课程一律用**课程号（courseId 主键）**，允许同名不同号。

### 3.6 教务手动调整（v3.6）

- 入口：课表点卡片 → 课程详情 →「调整本课」→ 手动调整弹窗
- 直接改排课条目（时间 / 教室），**不经排课线程 / 退火**；只校验硬约束 H1~H5，软约束不管
- 两种排他模式：
  - **本节**：只改被点击的那次课；
  - **整班（N 次课）**：列出该班全部现存课次，各行独立选星期 / 起始节 / 教室，一次提交做**原子整批校验 + 落库**（批内自撞也会被拦截）。
- 每次课是独立对象：同班各次课可各落不同时间 / 不同教室
- 不改周范围；课长 = 原条目跨度；改起始节时结束节不超作息最大节
- 失败即停在弹窗，按行号提示中文原因（该教室时段被占 / 与本班冲突 / 该教师此时段有课 / 容量不足 / 类型不符 / 范围越界 / 条目不存在），**整体不写库**
- 调完**不自动锁定**；如需本次结果在后续「自动排课 / 局部重排」保留，请随后在详情锁定该班（与手动调整正交、可叠加）

### 3.7 全校课表展示

- **横看周几、竖看第几节**（符合阅读习惯），周一至周日 × 每日节次，支持按周切换
- 同一时间格多班上课（不同教室）时，**多行卡片堆叠**显示，课程名 + 教室一目了然；卡片可点击直达详情
- 一格课程较多时展示前 2 张完整卡 + 1 张「更多 +N」卡位，点「更多」弹列表
- 多学时课程一次课跨连续多节（节次区间完整渲染，跨节不破）
- 无课时间格留空；课表卡片随**主题系统**着色
- 卡片详情动作：查看课程信息 / 锁定解锁本班 / **调整本课** / 删除此班 / 删除整课

### 3.8 筛选、详情与诊断

- **筛选**：按教师 / 教室 / 课程多选过滤课表，快速定位
- **课程详情**：点击课表卡片查看课程信息（每周课次 / 单次学时 / 教师 / 教室等）并在详情内完成锁定 / 调整 / 删除
- **失败诊断**：排不下时列出失败教学班与归因（无对应类型教室 / 容量不足 / 时间冲突），便于排查数据问题

### 3.9 快照、导出与界面

- **快照导入/导出**：完整工作区（课程 / 教学班 / 教师 / 教室 / 作息 / 排课结果 / 排课失败 / 锁定 / 学期周数）导出为单文件快照并可恢复
- **兼容**：快照内 `[Courses]`（课程实体）、`[Locks]`（锁定集）允许缺失——老快照仍能打开，课程由教学班行推导、锁定为空
- **工作区持久化**：记忆文件自动保存/恢复，支持 Ctrl+S 手动保存，防误关丢数据
- **结果导出**：把当前工作区导出为快照存档（供分享 / 备份 / 二次排课）
- **界面**：顶栏（保存 / 周切换 / 自动排课 / 排课错误 / 锁定 / 主题）+ 左侧侧边栏（新建 / 导入快照 / 导出快照 + 新增 / 删除 / 筛选）+ 右侧课表；**排课期间**自动排课 / 锁定 / 新建 / 导入 / 导出 / 新增 / 删除 / 筛选等入口一律禁用，防半截结果写盘

## 4. 典型使用流程

```
① 准备 CSV（教学班 / 教室 / 作息表，可加教师清单）
        ↓
② 点击「新建」，选择文件（导入即自动排课）
        ↓
③ 查看全校课表；用筛选 / 详情 / 排课错误核对
        ↓
④ 需要时：新增课程/教学班（最小排）、删除课程/班（删班不删课）
        ↓
⑤ 局部微调：点卡片 →「调整本课」挪时间/教室（只查硬约束）
        ↓
⑥ 定稿前「锁定」要保留的班；再次「自动排课」只动未锁定班
        ↓
⑦ 导出工作区快照存档（或退出自动记忆 / Ctrl+S）
```

## 5. 验证成果

**示例数据规模**：11 个教学班 · 6 门课程 · 23 间教室（普通/机房/操场）· 每天 8 节

| 项目 | 结果 |
|------|------|
| 自动排课 | 示例班全部排上，每班恰排够每周课次 |
| 冲突数（教室/班级/教师） | 0 |
| 容量 / 类型违规 | 0 |
| SA 相对贪心 | 总软成本 ≤ 贪心；时间/教室负载方差大幅压匀 |
| 锁定重排 | 锁定班条目逐字段不动，其余重排零冲突 |
| 新增班最小排 | 存量 0 扰动插入；拥挤场景升格局部重排询问 |
| 教务手动调整 | 整批原子落库；任一节冲突即整批拒绝且不写库；拒绝原因细分 R/C/T |
| 自动化测试 | 9 个 QtTest 套件全部通过 |

> 测试覆盖：CSV 解析与导出往返、快照往返（含 `[Courses]` / `[Locks]` 段与缺段容错）、冲突检测、贪心排课正确性、筛选判定、模拟退火（硬约束零违反、成本不劣于贪心、负载均匀性、同种子可复现、课次数守恒、多学时跨节、周末罚分）、锁定冻结与最小排零扰动、手动调整（容量/类型/范围/缺失拒绝、批内自撞、整批回滚不写库）、课表点击命中回归。

## 6. 技术架构概要

```
表现层（Qt Widgets：主窗口 / 弹窗 导入·筛选·新增·删除·锁定·详情·手动调整 / 课表 MVD）
   ↓
排课核心（贪心 + 模拟退火，纯逻辑、可单测；movable/冻结；冲突表拒绝保证硬约束零违反）
   ↓
编排 / 校验（ScheduleController：异步线程 + 最小排升格收口；core/schedule/manualmove 手动调整校验）
   ↓
数据层（CSV 导入/导出、九段工作区快照、记忆文件、内存数据仓库 + ID 索引查询）
   ↓
数据模型（课程 / 教学班 / 教师 / 教室 / 作息 / 排课条目）
```

- 四层严格分离，核心逻辑**不含界面代码**，可用自动化测试独立验证
- 纯 C++17 + Qt6 Widgets，无第三方依赖

## 7. 局限与后续规划

**当前局限**
- 单机版，无账号与角色区分，仅服务管理员排课
- 软约束权重为固定建议值，未在 GUI 暴露调节入口
- 手动调整仅改时间 / 教室，不支持删单节、补排缺失节、按周跳过
- 锁定粒度为整班（无单节冻结）；未做“手动结果自动排永久优先”的独立特性
- 全空工作区（教学班全删光）新建 / 重开暂不支持

**已规划的下一步**
- UI 视觉优化与主题可感知性（plan_v4.0 提案：课表卡之外的界面美观、主题色作用可感知）
- 教师个人课表、学生个人课表
- 选课与学生名单（选课后冲突检测预留）
- GUI 暴露软约束权重调节（均匀性 / 拆分 / 周末罚分的权衡滑块）
- 手动调整增强：整班刚性平移 / 一键同教室、批内自由挑课次、永久手动优先
- 全空工作区支持
